## Принятые решения

**Локализация**
- Переводы хранятся прямо в HTML как JS-объект — без внешних i18n библиотек. Осознанно: проект простой, лишняя зависимость не нужна.
- 61 ключ на язык.

**Скриншоты**
- Структура: `screens/<lang>/filename.jpg` с фолбэком на `screens/en/`
- Фолбэк реализован через JS `Image.onload/onerror` — без серверной логики
- Скриншоты для RU/UA/FR/DE/ES/IT пока пустые — добавляются по мере готовности, фолбэк работает автоматически
- Корневая папка `/screens/` устаревшая — не использовать

**Файлы**
- `fitence-workout-planner.html` — устаревший дубль, не использовать и не редактировать

**Git**
- Владелец может вносить правки напрямую в ветку — перед работой всегда делать `git pull`
- Работа в ветке `claude/<name>`, слияние в `main` — по явной команде: `main`
  деплоится автоматически, то есть пуш в него публикует сайт (2026-08-22)

**Юридические документы**
- `privacy.html` и `terms.html` **не переводятся** под 7 локалей (решено
  2026-08-22). Возвращаемся к вопросу с выпуском следующей версии приложения:
  там в этих документах будут изменения — тогда и решаем, переводить ли.
  Смысла переводить текст, который вот-вот поменяется, нет.
