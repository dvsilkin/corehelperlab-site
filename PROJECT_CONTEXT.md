## Принятые решения

**Локализация**
- Источник правды — `_i18n/`; страницы генерируются, каждый язык имеет свой URL с server-rendered HTML. Без внешних i18n-библиотек — осознанно, проект простой.
- 67 ключей на язык.
- `alt` картинок локализован через `data-i18n-alt` — английский `alt` на неанглийской странице считается ошибкой.
- Совпадения с английским, которые законны («Support» во французском, «Screenshots» в немецком, «Home» в итальянском), перечислены в `config.i18nSameAsEnglish`.

**Скриншоты**
- Структура: `screens/<lang>/filename.jpg` с фолбэком на `screens/en/`
- Фолбэк реализован через JS `Image.onload/onerror` — без серверной логики
- Все языковые папки заполнены локализованными скриншотами

**SEO**
- Длина `<title>` ≤ 60, `description` ≤ 160 — проверяется чекером
- `<meta name="keywords">` убран: поисковики его игнорируют, а был он только на английской странице
- `aggregateRating` в JSON-LD намеренно отсутствует — добавлять только по реальным цифрам из Play/App Store, выдуманные нарушают правила Google

**Git**
- Владелец может вносить правки напрямую в ветку — перед работой всегда делать `git pull`
